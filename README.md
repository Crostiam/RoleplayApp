🏰 Medieval Realm Chat & Roleplay App

Welcome, traveler, to the Medieval Realm! This is a feature-rich, real-time web application built for immersive text-based roleplaying, chatting, and community interaction. It features real-time synchronization, transient chat rooms, an infinite-canvas notice board, and integrated D20-style dice rolling.

✨ Features

🛡️ Character Creation & Presence

Secure Entry: Register with a unique username, display name, class/profession, and a secret passphrase.

Custom Portraits: Upload avatars that are automatically resized and optimized.

Live Presence & AFK Tracking: See who is currently in the room with you. A built-in heartbeat system automatically marks users as away/offline if they are inactive for 2 minutes.

🗺️ Realms (Chat Rooms)

Main Town: The central hub where chat history is permanently preserved for all travelers.

Transient Realms: In other rooms, chat history is transient—you only see messages sent after you entered the room, adding to the realism of walking into a tavern mid-conversation.

Pinned Messages: Users can permanently pin messages to a room so they remain visible to everyone, even after leaving and returning.

Custom Backgrounds: Admins can create new realms with custom names, icons, descriptions, and immersive background images.

📜 The Notice Board (Infinite Canvas)

Interactive Canvas: A sprawling, draggable, and zoomable infinite canvas where users can post "Decrees."

Rich Notices: Post text and paste images directly into decrees.

Draggable & Scalable: Admins and authors can drag notices around the board and scale their size up or down.

🦅 Ravens (Direct Mail)

Private Messaging: Send ravens (DMs) to other users currently in the roster.

Anti-Spam Cooldown: To maintain immersion, sending a raven triggers a 60-second cooldown (bypassed by Admins).

Master View: Admins have access to the "Intercepted Ravens" master view to monitor all realm secrets.

🎲 Roleplay Mechanics & Interaction

Player Interaction: Click on any player in the room or the roster to view their biography and initiate actions.

Quick Actions: One-click roleplay actions like Bow, Cheer, or Slap.

Custom Action Rolls: Attempt any custom action (e.g., "steal from", "charm") which automatically rolls a contested D20 (1-20) between you and the target to determine success, failure, or a tie.

Points System: Admins can award or deduct points for users based on roleplay actions or events.

🛠️ Technology Stack

Frontend: React, TypeScript, Tailwind CSS

Icons: Lucide React

Backend & Database: Firebase (Anonymous Auth & Firestore Realtime Database)
